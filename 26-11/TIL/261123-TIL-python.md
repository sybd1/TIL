#### Basic 문법
- 파이썬에서는 줄이 바뀌면 코드가 끝이 난다. 세미콜론을 붙이지 않아도 문제 없다.
- 자료형 없이 변수 선언하고 값을 넣을 수 있다.
- 변수 이름은 카멜 케이스가 아닌 파이썬에서는 단어와 단어 사이에 (_) 밑줄 스네이크 케이스를 관례적으로 사용한다.
- 문자열 작은 따옴표, 큰 따옴표 둘 다 사용 가능하다.
- 숫자열에 밑줄 아무 상관없다. 단지 읽기 쉬우려고 넣는다.
- 주석은 #을 사용하면 된다.

- f-string: 문자열 앞에 f를 붙이고 중괄호 안에 변수명을 넣으면 해당 값이 삽입된다.
- 리스트: 순서가 있고 내용을 변경할 수 있는 자료형. 값의 위치는 인덱스와 동일하다.
    - append(): 리스트 가장 끝에 추가.
    - insert(인덱스위치, 값): 해당 인덱스에 삽입.
    - pop(): 인덱스를 주지 않으면 맨 뒤 요소를 꺼내고 제거.

- 딕셔너리: 키와 값을 한 쌍으로 저장하는 자료형. 키가 없으면 새로 추가. 있으면 기존 값을 덮어쓴다. 존재하지 않는 키를 대괄호로 조회하면 KeyError 발생한다. get(키, 기본값)은 키가 없어도 오류 대신 기본값 반환.

#### String, Control Flow
- 슬라이싱: 문자열의 일부를 읽는다. [시작 인덱스 : 끝 인덱스] 시작을 생략하면 처음부터, 끝을 생략하면 끝까지.
- 제어문 if, for: Python은 중괄호 대신 들여쓰기로 블록을 구분한다. if문이나 for문 끝에 콜론을 쓰고, 다음 줄에서 들여쓰기 한 부분을 실행 범위로 인식한다.
- else if가 아니라 elif이다.
- for in 반복문: 리스트의 값을 하나씩 꺼내 반복한다.


#### Comprehension 문법
- 리스트 컴프리헨션: 반복과 조건을 이용하여 새 리스트를 만든다.


#### functions 함수와 타입 힌트
- def: define 함수를 정의하는 키워드. 함수의 매개변수에 기본값 설정이 가능하다. 매개변수에 타입 힌트를 적으면 어떤 것을 넣을지 미리 알려준다.


#### JSON, Exception
- 모델은 json으로 변환된 파일을 읽는다.
- 표준 라이브러리에 json은 포함되어 있다. import 구문만 추가하면 된다.
- json.dumps(): 파이썬 딕셔너리를 JSON 문자열로 변환하는 메서드.
- 모델이 응답한 JSON 문자열은 파이썬이 읽을 수 있게 딕셔너리로 변환해야한다.
- json.loads(): 모델이 응답한 JSON 문자열을 파이썬 딕셔너리로 변환하는 메서드.
- 모델이 응답할때 JSON 문법이 깨져있다면, 딕셔너리로 만들 수가 없다. 에러가 나기 때문에 예외처리를 해야 한다.
- try 문에서 except로 예외처리한다.

- json.decoder.JSONDecodeError: Expecting. 알맞지 않은 형식의 JSON 문자열 에러

#### LLM (Large Language Model) 대규모 언어 모델
- 많은 글과 코드를 학습해서 질문에 답하거나, 글을 요약하거나, 코드를 작성하는 데 쓰인다.
- 대표적인 생성형 LLM은 입력과 지금까지 작성한 내용을 바탕으로 다음에 올 토큰을 예측하며 답변을 만든다. 토큰은 모델이 글을 처리하는 단위로, 단어 하나일 수도 있고 단어의 일부일 수도 있다.
- 기준 데이터는 대문자를 관례적으로 사용한다.

#### Numpy
- 파이썬에서 숫자 배열을 다루고 계산하는 라이브러리이다. AI에 쓰이는 데이터도 숫자 배열로 다루고 계산할 수 있게 해 주는 도구이다.
