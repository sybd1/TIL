### JavaScript 기능
- JavaScript의 역할은 HTML에서 사용자가 입력한 값을 받아 가공해 실시간으로 브라우저 화면에 제공 해주는 것이다.
- 기본 구조는 Variable (변수), 함수, Obeject (객체), Property (속성), Method (매서드)
- 함수의 괄호 () 안에 들어가는 문자를 Argument (인수)라고 한다.
- 변수는 문자와 숫자, $, _만 사용가능하다.
- 첫글자는 숫자가 될 수 없다.
- 가급적 상수 const에 들어가는 변수는 모두가 잘 볼 수 있게 대문자로 적는다.
```text
- HTML 과 백엔드 사이에서 JavaScript가 하는 역할
[HTML 브라우저 화면] ── 1. 사용자가 입력
    │
    ▼
[JavaScript] ── 2. 즉시 검증 & UI 반응
    │── 3. 백엔드로 데이터 전송: fetch
    ▼           
[백엔드 서버 / DB] 
    │── 4. 처리 결과 데이터 반환: JSON
    ▼           
[JavaScript] ── 5. 받은 데이터를 HTML 태그 규격으로 가공
    │
    ▼
[HTML 브라우저 화면] ── 6. 최종 렌더링: 사용자가 눈으로 결과를 확인!
```

1. 사용자 행동 감지
    * 사용자의 버튼 클릭, 검색창에 글자 타이핑, 마우스를 올리는 등의 동작을 실시간으로 감지한다.
2. 입력, 변경값 실시간 가져오기
    * 사용자가 타이핑한 글자를 DOM 트리의 Proverty(input.value)를 통해 그 최신 상태값을 즉시 변수에 담아온다.
3. 데이터 가공 및 계산
    * 가져온 값을 토대로 사칙연산을 하거나, 유효한 값(비밀번호 8자리 이상 같은)인지 검사하거나, 조건문으로 분기 처리를 한다.
    > 조건문 분기 처리???
4. 화면을 바꾸거나 서버와 통신
    * 새로고침 없이 화면의 특정 글자나 스타일 변경.
    * 가공한 데이터를 벡엔드 서버로 보내 저장하거나 요청
> * 다수의 사람들이 데이터를 저장하고 상호작용으로 일어난 일들을 저장하고 싶다면 백엔드 서버와 DB (데이터 베이스)가 필요하다.
> * JavaScript가 HTML에서 받아온 정보는 가만히 놔두면 컴퓨터의 일시적인 임시 기억장치(RAM 메모리)에서만 처리하기 때문에 사라진다. 브라우저 창을 닫거나, 새로고침을 하면 변수에 들어있던 데이터는 완전히 사라진다.
> * 백엔드 서버 말고 브라우저에서 제공하거나 LocalStorage/SeessionStorage (로컬 저장소,간이 저장소)에 저장하는 것은 가능하다.

### Variable (변수)
 * 변수: 값을 저장하는 공간. 7개의 타입이 있다.
    * data type (데이터 타입)
        1.number (숫자 타입)
        2.string (문자열 타입)
        3.boolean (논리 타입)
        4.undefined & null
        5.symbol & object
1. number (숫자 타입)
- 자바 스크립트는 모든 수를 실수로 처리한다.
- 그외에 Infinity(양의 무한대) -Infinity(음의 무한대), NaN(not-a-number) 값도 표현한다.
2. string (문자열 타입)
- 텍스트 형태의 데이터를 담을 때 사용하는 자료형 '' 작은 따옴표,"" 큰따옴표,'' 백틱 안에 텍스트를 집어 넣으면 문자열 타입으로 인식한다. 백틱 안에 `${변수 값}` 이런 형식으로 집어 넣을 수 있다. ex) `My name is ${name}`
- 문자열 상자 뒤에 .length를 붙이면 공백을 포함한 전체 글자 수를 알려준다.
- 예약어 (Reserved Worde)는 자바스크립트의 고유한 문법 규칙 언어로 변수로 사용할 수 없다.
- 작은 따옴표 안에서 작은 따옴표가 겹치면 \ 백 슬래쉬를 앞에 입력해주면 특수문자로 인식한다. ex) 'I\'m a boy.'
3. boolean (논리 타입)
- true와 false 두 가지가 있다.
4. undefined & null
- undefined : 변수를 설정만 하고 값을 할당되지 않았을 때 출력.
- null : 존재하지 않는 값. 자바스크립트 자체 오류로 object로 나오기도 한다.
5. symbol & object

### 대화상자
1. alert
- 알림, 경고 값을 띄우는 기능. 확인 버튼 하나만 존재한다.
2. prompt
- 값을 입력하는 기능
```text
ex) const name = prompt("이름을 입력하세요.");
    alert(`환영합니다, + ${name} + 님`)
    출력 결과 : 1. 이름을 입력하세요. 대화상자
               2. 환영합니다 name 님
```
- 함수를 실행하는 괄호 안에 인수가 2개 들어가면, 앞에 오는 인수는 안내 문자가 되고, 뒤에 오는 인수는 텍스트 박스 안의 디폴트 값으로 출력 된다.
3. confirm
- alert와 다르게 확인과 취소 버튼 2개가 있다. 확인 버튼을 누르면 true라고 인식하고, 취소 버튼을 누르면 false로 인식한다.

        단점
        - 창이 떠 있는 동안 스크립트가 일시정지한다.
        - 위치와 모양 등 스타일링을 할 수가 없다.
