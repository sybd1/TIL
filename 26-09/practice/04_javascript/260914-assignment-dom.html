문제 1. 상품 이름 검색하기

  • 검색 버튼을 누르면 input의 현재 입력값을 가져옵니다.
  • 입력값의 앞뒤 공백을 제거하고 소문자로 바꿉니다.
  • querySelectorAll로 모든 상품 요소를 선택합니다.
  • 상품 이름에 검색어가 포함되면 matched 클래스를 추가하고, 포함되지 않으면 제거합니다.(for...of / includes 사용)
  • 일치한 상품 개수를 #search-result의 텍스트로 출력합니다.
  • 빈 검색어이면 모든 상품의 matched 클래스를 제거하고 결과에 안내 문구를 출력합니다.
  • 키보드
  • 무선 마우스
  • 모니터
  • 마우스 패드

검색 결과가 여기에 표시됩니다.

문제 4. dataset으로 선택 상품 표시하기

  • 상품 카드의 선택 버튼을 누르면 상품 번호가 selectProduct 함수에 전달됩니다.
  • 전달받은 상품 번호와 속성 선택자를 사용하여 해당 상품 카드를 선택합니다.
  • 선택한 카드의 dataset에서 상품 번호, 상품명, 가격을 가져옵니다.
  • 모든 상품 카드의 selected 클래스와 data-selected 어트리뷰트를 먼저 제거합니다.
  • 선택한 카드에만 selected 클래스를 추가합니다.
  • 선택한 카드에 data-selected="true" 어트리뷰트를 설정합니다.
  • 상품 정보를 #selected-product에 출력합니다.

문제 5. 프로필 카드 꾸미기

  • 적용 버튼을 누르면 이름 input과 소개 textarea의 현재값을 읽습니다.
  • 입력한 이름과 소개를 프로필 카드 안의 알맞은 요소에 textContent로 표시합니다.
  • 색상 input의 값으로 카드의 테두리 색상을 변경합니다.
  • 크기 select가 compact이면 compact 클래스를 추가하고, normal이면 제거합니다.
  • 다크 모드 버튼을 누를 때마다 dark 클래스를 토글합니다.
  • 카드가 현재 dark 클래스를 가지고 있는지 확인하여 버튼의 텍스트를 변경합니다.
