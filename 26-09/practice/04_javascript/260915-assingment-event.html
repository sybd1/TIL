HTML과 CSS는 작성되어 있습니다. 각 문제의 script 영역에 이벤트 처리 코드를 작성하세요.

문제 1. 클릭 이벤트 시작하고 중지하기

  • #count-button을 클릭할 때마다 횟수를 1씩 증가시켜 화면에 출력합니다.
  • 이벤트 핸들러는 이름이 있는 함수로 작성하고 addEventListener로 등록합니다.
  • 중지 버튼을 누르면 removeEventListener로 카운트 이벤트를 제거합니다.

클릭 횟수: 0

문제 2. 이벤트 위임으로 메뉴 선택하기

  • 각 버튼에 따로 이벤트를 등록하지 말고 #menu-list에 클릭 이벤트 하나만 등록합니다.
  • event.target.closest()로 클릭한 버튼을 찾습니다.
  • 메뉴 버튼이 아닌 곳을 클릭하면 아무 작업도 하지 않습니다.
  • 모든 메뉴의 selected 클래스를 제거한 뒤 선택한 메뉴에만 추가합니다.
  • 버튼의 dataset.menuId와 메뉴명을 결과 영역에 출력합니다.
  • 대시보드
  • 회원 관리
  • 상품 관리

선택한 메뉴가 여기에 표시됩니다.

문제 3. 기본 동작과 이벤트 전파 제어하기

  • 안내 열기 버튼을 누르면 배경에 open 클래스를 추가합니다.
  • 어두운 배경을 클릭하면 모달이 닫히도록 합니다.
  • 흰색 모달 내부를 클릭했을 때는 stopPropagation()으로 닫히지 않게 합니다.
  • 모달 안의 링크를 클릭하면 preventDefault()로 페이지 이동을 막고 안내 문구를 출력합니다.

링크 처리 결과가 여기에 표시됩니다.

문제 4. 키보드 입력 처리하기

  • input 이벤트가 발생할 때마다 공백을 포함한 현재 글자 수를 출력합니다.
  • keydown 이벤트에서 event.key가 Enter인지 확인합니다.
  • Enter를 누르면 입력값의 앞뒤 공백을 제거하여 결과 영역에 출력합니다.
  • 빈 값이면 메시지를 출력하지 않고 안내 문구를 표시합니다.
  • 메시지를 출력한 뒤에는 input과 글자 수를 초기화합니다.

현재 글자 수: 0

입력 결과가 여기에 표시됩니다.

문제 5. 회원가입 폼 검증하기

  • 폼의 submit 이벤트를 처리합니다.
  • 이름은 앞뒤 공백을 제거했을 때 두 글자 이상이어야 합니다.
  • 비밀번호는 여섯 글자 이상이어야 하며 약관에 동의해야 합니다.
  • 검증에 실패하면 preventDefault()를 호출하고 첫 번째 오류 메시지를 출력합니다.
  • 성공할 때도 페이지 이동을 막고 성공 메시지를 출력합니다.

검증 결과가 여기에 표시됩니다.
