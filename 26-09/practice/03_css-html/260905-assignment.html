펭귄 소개

Polar Penguin Explorer는 남극의 신비로운 펭귄에 대한 지식을 넓히고 탐험 데이터를 관리하는 페이지입니다. 펭귄의 종류, 특징, 서식지 정보를 한눈에 확인하세요.

이제 탐험을 떠나 우아한 펭귄의 데이터를 직접 기록해보세요.

주요 서식지

  • King George Island
  • Snow Hill Island
  • Ross Island
  • Gould Bay
  • Salisburry Plain
  • Deception Island
