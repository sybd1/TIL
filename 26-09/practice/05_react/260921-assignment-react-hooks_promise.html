Hooks와 Promise 실습

문제 1·2는 필수, 문제 3은 선택 심화입니다. 문제 1은 Console에서, 문제 2·3은 화면과 Console에서 결과를 확인하세요. Promise가 낯설다면 수업의 03_promise.html을 참고해도 됩니다.

문제 1. Promise로 순서가 있는 작업 처리하기 (필수)

  • addAfterOneSecond(number)가 Promise를 반환하도록 만드세요.
  • 1초 뒤 전달받은 숫자에 10을 더합니다. 결과가 30 이하이면 resolve(result), 30을 초과하면 reject(new Error('30을 초과했습니다.'))를 호출하세요.
  • 0부터 시작하여 작업을 계속 연결합니다. 성공한 결과를 Console에 출력하고 다음 Promise를 return하세요.
  • 10, 20, 30을 순서대로 출력한 뒤 다음 작업에서 실패하면 .catch()로 오류 메시지를 출력하세요.
  • 성공·실패와 관계없이 마지막에 .finally()로 작업 종료를 출력하세요.

예상 흐름: 시작 → 약 1초마다 10, 20, 30 → 오류 메시지 → 작업 종료
