React 컴포넌트와 Props 실습

아래 요구사항에 맞게 script 영역의 세 컴포넌트를 완성하세요.

  1. CourseHeader: title과 teacher를 props로 받아 제목과 강사명을 출력합니다.
  2. StudentCard: name, age, track을 구조분해 할당으로 받고 학생 정보를 출력합니다. track이 없으면 미정을 기본값으로 사용합니다.
  3. InfoPanel: title과 children을 받아 제목과 내부 내용을 출력합니다. title이 없으면 안내를 기본값으로 사용합니다.
  4. App: 완성한 컴포넌트를 조립합니다. StudentCard는 서로 다른 값으로 두 번 사용하고, 두 번째 카드에는 track을 전달하지 않습니다.
  5. App: InfoPanel의 여는 태그와 닫는 태그 사이에 두 개 이상의 JSX 요소를 넣어 children으로 전달합니다.
