## [2026-10-09] Java Class and Object

### 1. 오늘 배운 핵심 개념 (What I Learned)
#### Class, filed
- Class: 객체가 어떤 데이터(속성)와 어떤 기능(메서드)을 가져야 하는지 정의하는 설계도이다.
- Filed: 클래스 내부에 선언하여 객체 또는 클래스가 관리하는 데이터를 나타내는 변수이다. JS에서 단순하게 중괄호 안을 key,value property로 채우는 것과 다르게, 자바에서는 Class 내부에 객체를 만들어 속성(데이터)들을 가진다.
- 필드에 값을 대입하려면 '.' 마침표로 참조 연산자를 사용하면 된다.

#### Encapsulation (캡슐화)
- Encapsulation: 외부에서 참조연산자로 filed에 직접 관여해 아무 값이나 담고 변경할 수 있는 것을 방지하려고 규칙을 정한다.
**[접근 제한자]** : 클래스 혹은 클래스의 소속된 구성 요소(filed, method, constructor, 중첩 클래스 등)에 참조 연산자로 접근할 수 있는 범위를 제한하기 위한 키워드
* (+) public: 모든 패키지에서 접근 허용.
* (#) protected: 동일 패키지에서 접근 허용. (단, 상속관계에 있는 경우 다른 패키지에서도 접근 가능)
* (~) default: 동일 패키지 내에서만 접근 허용. (작성하지 않는 것이 default)
* (-) private: 해당 클래스 내부에서만 접근 허용.
* 다른 클래스 안에 포함되어 있지 않은 최상위 클래스는 public 또는 default만 사용 가능하다.

**[Getter / Setter Method]**
* Getter (접근자): 내부 필드의 값을 외부에 반환하는 메서드.
* Setter (변경자): 외부에서 전달된 값을 받아, 내부 필드의 값을 설정 또는 변경하는 역할

#### Abstraction (추상화)
- Abstraction: 복잡한 내부 구현은 숨기고, 외부에는 필요한 기능만 의미있는 이름으로 보여주는 방법.
- 프로그램에 필요한 특징과 기능만 알맞게 골라 객체로 표현하고, 사용하는 쪽에는 복잡한 내부 로직 대신 필요한 기능만 보여주는 설계 방식이다.
- 추상화를 잘할수록 코드를 간결하게 수정가능해 유지보수가 간단해진다. 추상화를 못할수록 하나를 고치면 다른 코드가 동작하지 않고 그러다가 줄줄이 다른 코드까지 뜯어 고쳐야 한다.


#### DTO (Data Transfer Object)
- DTO: 여러 데이터를 하나로 묶어 전달하기 위한 객체이다.
- 행동은 없고 데이터만 있는 객체이다. 데이터를 포장해서 여러 계층에 안전하게 나르는 상자. 혹은 관련 값들을 옮기는 상자라고 생각하면 좋다.
- DTO에서 사용하는 filed의 제한자는 모두 private로 지정한다.
- Intellij IDE에서 제공하는 기능으로 (Alt + Insert)를 누르면 Getter와 Setter를 자동으로 생성가능하다.
    - boolean 값은 변수명에 get을 관례적으로 붙이지 않는다.

#### Constructor (생성자)
- Constructor: 생성자는 new로 객체를 만들 때 호출되어 객체의 초기 상태를 정한다. 기본 생성자와 매개변수에 있는 생성자를 차례대로 호출하며, Setter로 나중에 값을 넣는 방식과 생성 시점에 필요한 값을 전달하는 방식을 비교한다.
- 이름이 클래스명과 반드시 동일해야 한다.
- 반환 타입을 쓰지 않는다.
- 클래스에 생성자가 하나도 없다면 컴파일러가 기본 생성자를 자동으로 추가해준다. 생성자가 하나라도 있으면, 기본 생성자를 반드시 만들어 줘야 한다.
- 실제 현업에서는 사용자에게서 입력받은 새로운 값으로 객체를 처음 만들 때 생성자를 많이 사용한다. 이미 존재하는 객체의 값을 수정할 때는 Setter나 별도의 변경 메서드를 활용할 수 있다.

### 2. 코드 예시 (Code)
```text

- 사용자 정의 자료형 문법
자료형 변수명 = new 클래스명();
Nmixx nmixx = new Nmixx();
nmixx.member = "배이";
nmixx.age = 23;
nmixx.gender = '여';

- 생성자 기본 문법
접근 제한자와 클래스명(매개변수) {
    필드 초기화 코드
}

```

### 3. 문제 해결 및 에러 (Troubleshooting / 헷갈린 점)
- new로 만들어지는 인스턴스 객체는 모두 Heap 메모리에 저장된다. Heap은 실제로 RAM에 저장되어 사용된다.
- Getter와 Setter는 외부 입장에서 직역하면 이해하기 쉽다. 외부에 있는 클래스가 받는 사람(Getter). 외부에 있는 클래스가 보내는 사람(Setter).
- switch case 문에서 case 1: 으로 설정하면, Scanner로 사용자에게 값을 입력 받아서 1을 선택하면 case 1번 문 안의 메서드가 실행되도록 할 수 있다.
