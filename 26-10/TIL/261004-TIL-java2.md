## [2026-10-04] Java 예습

### 1. 오늘 배운 핵심 개념 (What I Learned)

- if, else, else if 조건문도 JS와 동일하게 사용 가능하다.
- switch case: 경우에 따른 분기를 위해 사용한다. break, defaulf는 생략 가능 하다.
- 반복문
    - For: 반복문, JS 문법과 동일하다.
    - while: 다른 형태의 반복문. 선언을 미리하고, 증감값을 마지막에 두는 문법.
    - do while: 다른 형태의 반복문2. 일단 한번은 실행하는 반복문.
    - break: 반복문 중간에 추가하여 반복을 탈출할 수 있는 명령어.
    - continue: 반복문 중간의 명령을 건너뛸 수 있는 명령어.

- 배열: 같은 자료형의 값 여러개를 저장하는 연속된 공간
- 배열 순회: for 반복문을 사용해 배열의 각 요소에 접근 가능하다.
### 2. 코드 예시 (Code)
```text
- if 조건문
int num = 10;
if (num > 20) {
    System.out.println("num은 20보다 크다");
} else if (num > 10) {
    System.out.println("num은 10보다 크다"); 
} else {
        System.out.println("num은 10이다.");
}

- switch case
int bias = 1;
switch (bias) {
    case 1: 
        1System.out.println("설윤");
        break; 
    case 2: 
        System.out.println("지우");
        break; 
    default: 
        System.out.println("모두가 최애");
}

- For 반복문
for (int i = 0; i < 5; i++) {
    System.out.println("I LOVE NMIXX"); // 5번 출력
}

- while 반복문
int i = 0;
while (i < 5) {
    System.out.println("I LOVE NMIXX"); // 5번 출력
    i++;
}

- do while 반복문
int i = 0;
do {
    System.out.println("I LOVE NMIXX"); // 5번 출력
    i++;
} while (i < 5);

- 이중 반복문
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        System.out.println("I LOVE NMIXX"); // 명령문 2번 반복 x 명령문 3번 반복 = 6번 출력
    }
}

-break
for (int i = 0; i < 5; i++) {
    if (i == 3)
    break;
    System.out.println("I LOVE NMIXX"); // 3번 출력
}

- continue
for (int i = 0; i < 5; i++) {
    if (i == 2)
    continue;
    System.out.println("I LOVE NMIXX"); // 4번 출력
}

- 다양한 배열 문법
int [] numbers = new int[5];
// int numbers[] = new int[5]; 위와 방식이 다르지만 동일하게 사용가능하다.
numbers[0] = 1;
numbers[1] = 2;
numbers[2] = 3;
numbers[3] = 4;
numbers[4] = 5;

int [] numbers = new int[] {1,2,3,4,5};
int [] numbers = {1,2,3,4,5};

- 배열 순회
int [] numbers = {1,2,3,4,5};

for (int i =0; i < numbers.length; i++) {
    System.out.println(numbers[i]);     // 1,2,3,4,5
}

for (int number : numbers) {
    System.out.println(number);     // 1,2,3,4,5
}
```
