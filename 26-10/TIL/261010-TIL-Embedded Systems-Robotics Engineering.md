## [2026-10-10] Embedded Systems, Robotics Engineering

### 1. 오늘 배운 핵심 개념 (What I Learned)
#### 용어 설명
- Robotics Engineering: 로봇의 움직임, 센서, 경로를 제어하고 판단하며 구현한다.
- Embedded Systems: 기계 내부의 컴퓨터에 들어가는 소프트웨어 개발.
    - Chip: 전자 기능을 수행하는 작은 반도체.
        - MCU: Chip 안에 CPU, 메모리, 입출력 제어 회로 등을 통합한 소자. 기계나 전자기기를 제어. 센서 값을 읽거나 모터를 켜고 끄는 역할.
    - Module: 특정 기능을 수행하도록 구성한 부품 단위.
    - Development Board(개발 보드): 쉽게 프로그래밍하고 센서나 모터를 연결할 수 있도록 여러 부품을 한 기판에 모아놓은 제품.
    - ESP32: 칩, 모듈, 개발보드 등이 설치된 제품 이름. Wi-Fi와 블루투스 통신 기능을 갖춘 마이크로컨트롤러 계열.

- Actuator: 전기 명령을 실제 움직임이나 작용으로 바꾸는 부품. 모터 같은 것들.
    - 일반 DC Motor: 전원을 공급하면 회전한다.
    - Servo Motor: 목표 위치나 속도 등에 맞춰 움직이도록 제어한다.
- Jumper wire: 부품과 부품을 연결하는 전선.
- Ground/GND(접지/기준점): 회로에서 전압을 비교하는 기준이 되는 연결.

- Firmware: 기기 안에서 실행되는 프로그램. 예: "휴대폰 명령을 받으면 서보모터를 90도로 움직여라."

- Arduino: 센서나 모터 같은 장치를 제어할 수 있는 오픈소스 마이크로컨트롤러 기반의 피지컬 컴퓨팅 플랫폼. 아두이노 IDE에서 C,C++로 코드를 작성한다.


#### 제작 순서
1. 하드웨어 준비
    - ESP32 개발보드, SG90 서보모터, USB 전원, 점퍼선 등을 준비하고 데이터시트에서 핀 배치와 전압 조건을 확인.
2. 회로 연결
    - 전원과 GND, GPIO 제어선을 연결. 극성과 허용 전압을 확인하고 합선이 없는지 전검.
3. 펌웨어 작성
    - IDE에서 ESP32 프로그램을 작성하고 컴파일한 다음 보드에 업로드.
4. 모터 제어
    - PWM 제어 신호를 이용해 SG90을 지정한 각도로 움직여. 모터가 움직일 때 전원 부족이나 재부팅이 발생하지 않는지도 확인.
5. 무선 통신
    - Wi-Fi와 HTTP를 이용해 스마트폰의 명령을 받아. 시리얼 모니터로 연결 상태와 명령 처리 결과를 확인.
6. 실제 장치에 적용
    - 충분한 테스트이후 가동을 한다.

### 3. 문제 해결 및 에러 (Troubleshooting / 헷갈린 점)
- USB가 충전만 가능하고, 데이터를 불러오는 기능이 없을 수도 있다는 것을 몰랐다. USB 드라이버 업데이트를 해야 데이터를 가지고 올 수 있는 지도 몰랐다.
    - Carge-only cable: 전력 공급이 목적.
    - Data/Sync cable: 충전과 데이터 전송 모두 가능.
    - 장치관리자 (win + x)에서 포트(COM & LPT)를 확인해 정상적으로 보드가 연결되었는지 확인 가능하다.
- 2.4GHz 와이파이는 최대 전송 속도는 느리지만, 벽을 통과하고 통신 거리가 넓어 스마트 가전, lot, 센서 등에 유리하다. 5GHz 와이파이는 반대이다. 서로 역할이 다르다.
- 서보모터가 3핀 커넥터로 된 제품이라, ESP32 원하는 위치에 꽂을 수가 없다.
    - 아두이노용 암수점퍼선을 구매해서 해결했다.
- 개발보드에 잘못된 선을 연결하면 보드가 타거나, 그 핀이 죽을 수도 있다. 조심해야한다.
- Arduino IDE에서 코드를 작성한 뒤 저장하고, 해당 개발 보드에 맞는 Boards Manager를 찾아 install하고, Compile하고 보드에 업로드 해야 해당 코드의 기능을 작동한다.
